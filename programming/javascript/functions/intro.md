# Introduction to Functions

Functions let you reuse a block of code.

## Defining a function

```javascript
function greet(name) {
  console.log("Hello, " + name);
}
```

## Calling a function

```javascript
greet("Omkar");
```

This produces:

```text
Hello, Omkar
```
